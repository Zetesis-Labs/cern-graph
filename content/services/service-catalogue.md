# The service catalogue (SE/FE)

Since 2011 CERN has run service management on **ITIL** and ServiceNow, with a catalogue
that is deliberately **two-dimensional**: a **Service Element (SE)** is the service as
the user meets it, and a **Functional Element (FE)** is the tool, function or activity
that supports it — and it is at FE level that supporters and experts are declared. The
same system can therefore appear once as something you request and once as something
somebody maintains, which is exactly the distinction an operational graph needs.
