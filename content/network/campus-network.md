# The campus network

The site-wide network for offices, laptops and everything that is not an accelerator.
It carries **CERN-Campus**, the encrypted general-purpose wireless network, and
**eduroam** so visiting researchers arrive already authenticated by their home
institution. It is deliberately the *least* trusted of CERN's networks — the one from
which the technical network must be protected.
