# CIS Critical Security Controls v8

The **CIS Controls v8** family is a prioritized set of practical, measurable safeguards
for defending systems and networks against prevalent attacks. It is the external
baseline against which CERN's 2023 cybersecurity audit assessed the Organization; the
audit itself is a historical assessment, not the standard.
