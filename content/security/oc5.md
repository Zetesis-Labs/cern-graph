# OC5 — the Computing Rules

CERN's digital constitution. OC5 governs the use of **all** computing facilities —
networks, devices, data-centre services, applications — for staff and visitors alike.
Ignorance does not exempt; sanctions run from bandwidth throttling to outright
blocking. Detail lives in the [[subsidiary-rules]].
