# CERN Service Availability Overview

The Service Availability Dashboard.

## What it anchors

* It displays the **technical status** of CERN computing services, complementing the human-written announcements of the Status Board.
* Its initial version was called **Service Level Status (SLS)** — the name the URL still carries.
