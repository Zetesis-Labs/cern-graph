# PaaS for web applications with OpenShift Origin

CHEP paper by the CERN Web Frameworks team (CERN Document Server, record 2296657).

## What it anchors

* OpenShift leverages **Docker containers and Kubernetes orchestration** to provide a Platform-as-a-Service oriented to web applications, deployed to improve efficiency in computing resource usage.
* It was integrated with the other services around it: source control, web site management and **authentication**.
