# The CERN Data Centre

CERN's page on its data centre.

It provides an overview of the computing facility located at the Meyrin site, which functions as the primary Tier-0 site for WLCG data storage and processing. The documentation details the data centre's physical infrastructure, power usage, and thousands of compute cores handling LHC experiment data. It also highlights the dual-centre operational model linked with the [[prevessin-computing-centre]] to ensure uninterrupted facility availability.

## What it anchors

* The Meyrin data centre as the long-standing hub of CERN computing and the Tier-0 of the WLCG, now complemented by the Prévessin centre.
