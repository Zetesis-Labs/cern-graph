# CERN IPv6 service description

The IPv6 service description.

It outlines the dual-stack operational model where IPv6 addresses are allocated and registered alongside IPv4 using [[landb]]. The service documentation reflects the production-grade deployment required to support high-throughput data transfers across WLCG grid sites. This ensures seamless network interoperability between CERN's computing infrastructure and external collaborating institutes.

## What it anchors

* CERN runs IPv6 alongside IPv4 as a service with its own addressing plan and registration path.
