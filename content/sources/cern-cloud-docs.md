# CERN OpenStack Private Cloud Guide

The CERN cloud service documentation.

## What it anchors

* The CERN Private Cloud is an **Infrastructure-as-a-Service** layer integrated with CERN's computing facilities, provisioning **over 90% of the infrastructure** in the computer centre.
* Container orchestration through **OpenStack Magnum** (Kubernetes clusters as a self-service resource) and bare metal through **OpenStack Ironic**.
