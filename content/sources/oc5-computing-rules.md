# CERN Computing Rules (Operational Circular No. 5)

The Computer Security team's authoritative index of OC5 and its subsidiary rules.

## What it anchors

* OC5 governs the use of all CERN computing facilities, networks, devices, data centre services and applications.
* The Computer Security Officer's mandate: protect the operations and reputation of the Organization against cyber-threats, including verifying that the rules are followed.
* The subsidiary rule families: Identities, Authentication & Authorisation (IAA), Software Restrictions (SWR), Networking (NET), Endpoints (EPT), IT Service Operations (OPS), Data Protection & Privacy (DPP), Software Development (DEV).
