# CERNphone documentation

The CERNphone service documentation.

## What it anchors

* CERNphone is a softphone service with a **dedicated SIP backend**, configuration and provisioning web interfaces, and two clients: **CERNphone mobile**, based on the open-source **Linphone** VoIP client and customised for CERN, and **CERNphone desktop**, developed at CERN.
* It replaced both **Skype for Business** (2013–2021) and the **Alcatel IP phones** (2006–2014).
