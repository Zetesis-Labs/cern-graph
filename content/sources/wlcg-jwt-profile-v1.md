# WLCG Common JWT Profiles v1.0 (2019)

The first published version of the profile (Zenodo, DOI 10.5281/zenodo.3460258, 25 September 2019).

## What it anchors

* The original lifetime table: access/ID token **20 minutes** (5 min–6 h), refresh token **10 days** (1–30 days), public key cache 6 h (1 h–1 day), issuer key 6 months.
* These are the values still circulating in summaries and slide decks; the current profile supersedes them.
