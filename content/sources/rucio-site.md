# Rucio — Scientific Data Management

The Rucio project site.

## What it anchors

* Rucio is an **open-source scientific data management system** created at CERN for exa-scale data needs.
* It organises, manages and provides access to data spread across globally distributed, heterogeneous data centres, **uniting different storage and network technologies as a single federated entity**, driven by customisable policies.
