# CIS Critical Security Controls Version 8

A prescribed set of prioritized cybersecurity best practices and defensive actions
formulated by the Center for Internet Security.

## What it anchors

* The baseline framework used for CERN's 2023 external cybersecurity audit.
* Practical safeguards designed to be focused, feasible, measurable and aligned with other frameworks.
