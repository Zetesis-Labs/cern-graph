# WLCG Technical Design Report

The foundational Technical Design Report (CERN-LHCC-2005-024) describing the computing architecture required to process, store, and analyze the data produced by the Large Hadron Collider.

## What it anchors

* The establishment of the multi-tiered grid computing model (Tier-0, Tier-1, Tier-2, Tier-3).
* The definition of CERN's Tier-0 obligation to safeguard the raw data's first copy and perform first-pass reconstruction.
