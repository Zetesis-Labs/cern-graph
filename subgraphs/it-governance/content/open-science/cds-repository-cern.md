# CDS and repository.cern

The CERN Document Server — the laboratory's institutional repository for two decades —
still runs **Invenio framework v1**. Its successor at `repository.cern` is built on
[[inveniordm]], and content migrates collection by collection: the first (Summer
Student Programme reports) landed in late 2024, with phases through 2026 and beyond.
