# Invenio framework ≠ InvenioRDM

A distinction the corpus enforces because getting it wrong is common: **Invenio** is a
framework (v1 powers the old CDS, v3 powers CERN Open Data); **InvenioRDM** is the
turn-key repository application built on that framework and on Zenodo's experience;
and **Zenodo** is a hosted service running InvenioRDM. Saying "X is built on
InvenioRDM" is only true for Zenodo and the new `repository.cern`.
