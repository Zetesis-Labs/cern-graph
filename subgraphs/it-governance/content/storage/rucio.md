# Rucio

An open-source scientific data management system created at CERN for exa-scale needs.
Rucio organises, manages and provides access to data spread across globally distributed
and heterogeneous data centres, **uniting different storage and network technologies as
a single federated entity** under customisable policies. Born in ATLAS, it is now used
by scientific communities well outside high-energy physics.
