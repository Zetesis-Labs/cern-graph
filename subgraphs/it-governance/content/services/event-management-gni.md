# Event management through GNI

The General Notification Infrastructure connects the monitoring plane to the ticketing
plane: hardware, network, operating-system and application alarms **generate incidents
automatically** in ServiceNow. It is the difference between a dashboard someone must
watch and a queue someone must answer — the alarm arrives with an owner and a clock.
