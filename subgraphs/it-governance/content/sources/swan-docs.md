# SWAN documentation

The SWAN service documentation.

## What it anchors

* SWAN is a Jupyter-notebook platform where **CERNBox is the home directory**, **CVMFS delivers the software environments**, and analysis can scale out to **Spark** or to the batch system through **Dask/HTCondor**.
* It also integrates **Rucio** for browsing and accessing distributed datasets.
