# CERNBox documentation

The CERNBox service documentation.

## What it anchors

* CERNBox is CERN's cloud storage: store, share and synchronise across devices, with **EOS** as the underlying storage.
* Access through the web, desktop sync clients (Windows/Mac/Linux), mobile apps, WebDAV, SSHFS and CIFS/SMB.
* Integrated collaborative applications — Office Online, Collabora, Jupyter notebooks — plus project spaces, versioning and a trash bin.
