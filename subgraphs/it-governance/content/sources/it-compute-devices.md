# IT Compute and Devices group

CERN IT's current description of the group responsible for scientific compute
and end-user devices.

## What it anchors

* Operation of scientific and interactive compute infrastructure.
* Linux distribution support and provisioning of physical and virtual compute.
* Windows and macOS support, endpoint configuration and Windows terminal
  services.
