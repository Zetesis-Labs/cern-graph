# CERN Tape Archive documentation

The CERN Tape Archive project documentation.

## What it anchors

* CTA is the **tape backend to disk systems**: in conjunction with EOS it manages the data of the LHC experiments.
* It is the evolution of CASTOR, removing the need to maintain a second disk-management system alongside the archive.
