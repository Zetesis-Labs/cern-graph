# LanDB network management

The cloud guide's section on LanDB.

## What it anchors

* **Every device on the CERN network must be registered in LanDB** — it is the authoritative inventory, not a convenience.
* LanDB **sets** group hosts so that firewall openings can be granted to a service rather than to individual addresses.
