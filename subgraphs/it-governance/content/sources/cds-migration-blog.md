# What's up on CDS — migration to InvenioRDM

The CERN Document Server team's news blog.

## What it anchors

* CDS is powered by **Invenio framework version 1** and is over 20 years old.
* The new CDS at `https://repository.cern` is **built on InvenioRDM**; the first collection (Summer Student Programme reports) migrated in late 2024, with a plan spanning 2024–2025 and a subsequent phase in 2026.
