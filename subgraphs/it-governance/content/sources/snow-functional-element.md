# ServiceNow as a Functional Element

The Functional Element page for `service-now` in the CERN Service Portal.

## What it anchors

* The system that runs the catalogue **has its own entry in the catalogue** — ServiceNow is itself a Functional Element with its supporting team, subject to the same incident and change processes as everything else it administers.
