# OpenID Connect Core 1.0 Specification

The specification defining the core OpenID Connect functionality, including authentication built on OAuth 2.0, claims communication, and standard discovery endpoints.

## What it anchors

* The use of standard OAuth2/OIDC flows and well-known discovery endpoints for integrating applications into CERN's SSO.
* The protocol substrate that enables capability-based authorization using scopes in the grid federation.
