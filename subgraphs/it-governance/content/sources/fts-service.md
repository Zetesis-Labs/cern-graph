# File Transfer Service (FTS)

The FTS project site.

## What it anchors

* FTS performs **reliable file transfers across sites**, including third-party transfers, with queuing, scheduling and retries.
* Developed at CERN, it distributes the majority of LHC data across the WLCG infrastructure — **up to petabytes per month** — with checksums, retries and multiprotocol support.
