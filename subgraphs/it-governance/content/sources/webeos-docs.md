# WebEOS hosting documentation

The WebEOS service documentation.

It describes the technical deployment and administrative guide for hosting websites using WebEOS at CERN. The service leverages the OKD4 OpenShift container platform to render web content stored directly in [[eos-docs]]. It details the self-service management model, custom domain configuration, and seamless integration with [[cern-sso]] for access control.

## What it anchors

* The service infrastructure is built on the **OpenShift Kubernetes platform (OKD4)** and is **fully self-service**: users administer their own project (Kubernetes namespace).
