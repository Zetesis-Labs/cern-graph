# OpenStack Documentation

The primary documentation repository for OpenStack, detailing the architecture, deployment, and management of its various infrastructure services.

## What it anchors

* The technical foundations of CERN's private cloud, detailing the self-service provisioning mechanisms of OpenStack Magnum for Kubernetes and OpenStack Ironic for bare metal.
