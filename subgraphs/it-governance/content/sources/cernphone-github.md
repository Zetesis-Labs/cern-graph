# CERNphone applications on GitHub

The CERNphone organisation on GitHub.

It hosts the public source code repositories for the CERNphone desktop and mobile user clients. The open repository model allows transparent development for Windows, macOS, Linux, Android, and iOS software components. This public codebase embodies CERN's [[malt]] initiative strategy of replacing proprietary vendor solutions with open-source software.

## What it anchors

* The client applications are developed in the open, consistent with the open source policy.
