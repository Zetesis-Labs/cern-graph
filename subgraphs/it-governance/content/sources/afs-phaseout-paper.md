# CERN AFS phaseout: status and plans

CHEP paper by Jan Iven and Alberto Pace on the AFS phase-out.

## What it anchors

* The migration was officially restarted in **January 2019**, aiming to stop the AFS service before LHC Run 3.
* Where the use cases went: **live data to EOS**, which already had a filesystem interface, and **shared software to CVMFS**, already adopted by the LHC experiments for software delivery.
* CERNBox is described as built **on top of EOS** as a customised ownCloud service, adding web sharing and asynchronous sync.
