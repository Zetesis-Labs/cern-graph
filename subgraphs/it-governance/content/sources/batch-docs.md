# CERN Batch Docs (HTCondor)

The Batch Service documentation.

## What it anchors

* The CERN batch service provides **High Throughput Computing based on HTCondor**.
* The standard entry point is submitting jobs from **lxplus**, available to users of the CERN Linux service.
